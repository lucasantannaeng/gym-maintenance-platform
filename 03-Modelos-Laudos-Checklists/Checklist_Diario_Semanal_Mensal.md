## CHECKLIST DIÁRIO (Inspeção Visual Rápida - 5 min/equipamento)
*Executado por: Instrutor / Monitor / Zelador*
*Frequência: **Diária** (antes da abertura)*

| Item | Verificação | OK | Não OK | Ação Imediata |
|------|-------------|----|--------|---------------|
| 1 | **Aspecto geral**: limpo, sem suor/poeira acumulada | ☐ | ☐ | Limpar |
| 2 | **Cabos visíveis**: sem fios soltos, cortes, oxidação aparente | ☐ | ☐ | **INTERDITAR** + chamar manutenção |
| 3 | **Polias visíveis**: giram livre, sem ruído estranho | ☐ | ☐ | Chamar manutenção |
| 4 | **Travas de segurança**: engatam/desengatam (pinos, cliques) | ☐ | ☐ | **INTERDITAR** se não travar |
| 5 | **Pino seletor** (seletorizado): trava em todas posições | ☐ | ☐ | **INTERDITAR** se não travar |
| 6 | **Estofados**: sem rasgos com espuma exposta | ☐ | ☐ | Sinalizar / trocar |
| 7 | **Pegadores**: fixos, antiderrapantes, inteiros | ☐ | ☐ | Trocar se danificado |
| 8 | **Ajustes** (assento, encosto): movem e travam | ☐ | ☐ | Não usar posições que não travam |
| 9 | **Limitadores amplitude**: no lugar, funcionam | ☐ | ☐ | Não usar se ausentes |
| 10 | **Piso ao redor**: seco, limpo, tapete antiderrapante no lugar | ☐ | ☐ | Secar / recolocar tapete |
| 11 | **Parada emergência** (cardio): acessível, testa (botão) | ☐ | ☐ | **INTERDITAR** cardio se falhar |
| 12 | **Console/Display** (cardio): liga, mostra dados | ☐ | ☐ | Chamar manutenção |
| 13 | **Ruídos anormais** durante teste rápido (1 rep) | ☐ | ☐ | Chamar manutenção |
| 14 | **Sinalização/advertências**: legíveis, no lugar | ☐ | ☐ | Recolocar / substituir |

## CHECKLIST SEMANAL (Inspeção de Segurança e Ajuste - 15 min/equipamento)
*Executado por: Técnico de Manutenção / Responsável Técnico*
*Frequência: **Semanal** (dia fixo, ex: segunda-feira manhã)*

### Inclui TODOS itens do Diário +

| Item | Verificação | OK | Não OK | Ação |
|------|-------------|----|--------|------|
| 15 | **Aperto parafusos estrutura** (chave/torquímetro amostral) | ☐ | ☐ | Apertar / registrar |
| 16 | **Lubrificação guias/hastes** (spray silicone/PTFE seco) | ☐ | ☐ | Lubrificar |
| 17 | **Lubrificação cabos** (silicone seco - NÃO óleo/graxa no revestimento) | ☐ | ☐ | Lubrificar |
| 18 | **Polias**: folga axial/radial, alinhamento (visual + giro manual) | ☐ | ☐ | Ajustar / trocar rolamento |
| 19 | **Tensionadores cabos**: tensão correta (indicador ou folga ~10mm) | ☐ | ☐ | Ajustar |
| 20 | **Pilha pesos**: hastes guias limpas, buchas OK, pesos encaixam | ☐ | ☐ | Limpar / trocar buchas |
| 21 | **Pino seletor**: corda/presilha íntegra, trava todas posições | ☐ | ☐ | Trocar corda / pino |
| 22 | **Eixos articulações**: folga, lubrificação ponto graxa | ☐ | ☐ | Lubrificar / avaliar troca |
| 23 | **Soldas estrutura**: inspeção visual próxima (lanterna) | ☐ | ☐ | Registrar / interditar se trinca |
| 24 | **Pintura/galvanização**: pontos corrosão, retoque necessário | ☐ | ☐ | Agendar retoque |
| 25 | **Ancoragem** (outdoor/fixos): chumbadores apertados (torquímetro) | ☐ | ☐ | Apertar / registrar |
| 26 | **Drenagem** (outdoor): furos/base livres, sem água parada | ☐ | ☐ | Desentupir |
| 27 | **Piso amortecimento** (outdoor): íntegro, HIC visual | ☐ | ☐ | Agendar troca |
| 28 | **Elétrico cardio**: cabo alimentação, plug, aterramento visual | ☐ | ☐ | Chamar eletricista se dano |
| 29 | **Teste funcional completo**: 5 reps em cada ajuste principal | ☐ | ☐ | Registrar anomalias |
| 30 | **Registro**: preencher ficha equipamento, assinar, arquivar | ☐ | ☐ | Obrigatório |

## CHECKLIST MENSAL (Revisão Técnica Completa - 30-60 min/equipamento)
*Executado por: Engenheiro Mecânico / Técnico Habilitado Sênior*
*Frequência: **Mensal** (ou trimestral para baixo fluxo)*

### Inclui TODOS itens Semanal +

| Item | Verificação | OK | Não OK | Ação / Medição |
|------|-------------|----|--------|----------------|
| 31 | **Cabos**: inspeção DETALHADA (fios rompidos/10d, terminais, diâmetro) | ☐ | ☐ | Medir / Trocar se >5% fios |
| 32 | **Polias**: desmontagem visual rolamento/bucha, canal, flanges | ☐ | ☐ | Trocar se desgaste >1mm canal |
| 33 | **Eixos/Articulações**: folga radial/axial (relógio comparador) | ☐ | ☐ | Radial>0,15 Axial>0,5 = trocar |
| 34 | **Rolamentos**: ruído, temperatura, jogo (após 5min uso) | ☐ | ☐ | Trocar se anormal |
| 35 | **Molas a gás**: força retorno (dinamômetro), vazamento, haste | ☐ | ☐ | Trocar se <70% força nominal |
| 36 | **Pilha pesos**: alinhamento hastes, amortecedores, carenagem | ☐ | ☐ | Alinhar / trocar amortecedor |
| 37 | **Estrutura**: trincas (DP/US se suspeita), corrosão, deformação | ☐ | ☐ | Interditar se trinca estrutural |
| 38 | **Ajustes**: força acionamento (dinamômetro ≤30N), escalas | ☐ | ☐ | Ajustar mola/trava / regravar escala |
| 39 | **Limitadores**: posição, trava, não interferem movimento normal | ☐ | ☐ | Reposicionar / trocar |
| 40 | **Partida assistida**: força ≤50N, retorno suave, sem vazamento | ☐ | ☐ | Trocar mola gás |
| 41 | **Elétrico cardio**: aterramento (≤10Ω), isolação (≥1MΩ/500V), termografia | ☐ | ☐ | Registrar valores / corrigir |
| 42 | **Motor/inversor cardio**: corrente, temperatura, vibração (analisador) | ☐ | ☐ | Registrar / agendar revisão |
| 43 | **Calibração** (se aplicável): cargas, velocímetros, wattímetros | ☐ | ☐ | Certificado calibração RBC |
| 44 | **Documentação**: manual presente, fichas preenchidas, ARTs arquivadas | ☐ | ☐ | Completar faltantes |
| 45 | **Treinamento equipe**: checklists diários/semanais sendo feitos? | ☐ | ☐ | Reciclar equipe |
| 46 | **Estoque peças**: cabos, pinos, rolamentos, molas, estofados, pegadores | ☐ | ☐ | Repor mínimos |
| 47 | **Laudo fotográfico**: fotos geral + detalhes não conformidades | ☐ | ☐ | Anexar ao relatório mensal |
| 48 | **Relatório mensal**: emitir, assinar, entregar cliente, arquivar | ☐ | ☐ | Obrigatório |

## LEGENDA DE GRAVIDADE

| Nível | Definição | Prazo Correção | Uso Durante Correção |
|-------|-----------|----------------|---------------------|
| **CRÍTICA** | Risco iminente de acidente grave/morte (cabo prestes a romper, estrutura trincada, travamento falha, choque elétrico) | **IMEDIATO** | **INTERDITADO - PROIBIDO USO** |
| **MAIOR** | Risco de acidente médio, degradação rápida, não conformidade NR-12/ISO clara | ≤ 7 dias | Restrito / Supervisionado / Parcial |
| **MENOR** | Estética, ruído, conforto, desgaste inicial, não afeta segurança imediata | ≤ 30 dias | Liberado (monitorar) |
| **OBSERVAÇÃO** | Item em monitoramento, tendência de degradação, melhoria recomendada | Próxima inspeção | Liberado |
